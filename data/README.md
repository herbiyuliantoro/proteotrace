# Data in this repository

Tracked files include public sample metadata, derived abundance matrices and
analysis summaries. The two large source exports below are downloaded
separately.

## Inputs you need to fetch

| File | Size | Source |
|---|---|---|
| `PXD004242/MaxQuant_Output.zip` | 109 MB | `https://ftp.pride.ebi.ac.uk/pride/data/archive/2016/12/PXD004242/MaxQuant_Output.zip` |
| `PXD062541_report.tsv` | 106 MB | `https://ftp.pride.ebi.ac.uk/pride/data/archive/2026/01/PXD062541/report.tsv` (the third validation cohort, `analysis_pxd062541.py`; also the exploratory sex check) |

```sh
curl -L -o data/PXD004242/MaxQuant_Output.zip \
  https://ftp.pride.ebi.ac.uk/pride/data/archive/2016/12/PXD004242/MaxQuant_Output.zip
python extract_pxd004242_matrix.py
curl -L -o data/PXD062541_report.tsv \
  https://ftp.pride.ebi.ac.uk/pride/data/archive/2026/01/PXD062541/report.tsv
```

The PXD062541 report is a DIA-NN export written with decimal commas
(`7,04E+12`); the tool's reader handles that. The local copy used here has
sha256 `88cd291cb2472635c97644191608fc73f1b6f3562fb5924d92e7e2b883832f25`.

## What is tracked, and why

- `PXD001064_protein_matrix.tsv`, `PXD004242/PXD004242_protein_matrix.tsv` —
  the two quantitative matrices the figures are built from. Tracking them
  means every figure can be regenerated without the 109 MB download.
- `*_sample_info.txt`, `*_biological_samples.tsv`, `*sdrf.tsv`,
  `*_file_manifest.tsv` — sample and run annotation, including the SDRF used to
  reconcile the PXD004242 design.
- `*.json` and small `*.tsv` summaries — the frozen results each analysis
  script wrote. The figure scripts read these summaries and, where needed,
  the tracked matrices and pair-score tables.
- `PXD001064_primary.json`, `PXD004242/PXD004242_primary_random200.{json,tsv}` —
  the primary estimand for both cohorts, with the four-step ablation (raw,
  scaling only, batch only, both), the secondary estimands, the 200 PXD004242
  draws and donor-cluster bootstrap CIs. Written by `analysis_primary_estimand.py`.
- `PXD004242/PXD004242_primary_pairs_median.tsv` — per-pair scores for the
  median random assignment, written by `export_pxd004242_pairs.py`. That script
  refuses to write if it no longer reproduces the independently verified AUCs.
- `PXD062541_primary.json` and `../examples/PXD062541_samples.tsv` — the third
  cohort through the tool at its defaults, with the coverage sensitivity
  analysis. Written by `analysis_pxd062541.py`.
- `tool_validation.json`, `PXD004242/PXD004242_tool_visit_curve.json` — what the
  shipped tool catches on planted swaps, overall and by visits per donor.
  Written by `validate_tool.py` and `analysis_tool_visit_curve.py`.
- The earlier within-plate-group and rotation summaries
  (`PXD004242_random200_restricted.json`, `PXD004242_rotation_*.json`,
  `PXD004242_swap_reference_curve_summary.json` and neighbours) are kept as
  secondary analyses. No main figure reads them any more.

## What is not tracked

Large per-pair tables for the fixed-replicate diagnostics and the
leave-one-plate-out folds. Any of them is regenerated by rerunning the script
that produced it; none is an input to a main figure.

## Provenance

All three cohorts are public: PXD001064 (Liu et al., twin plasma, DIA/OpenSWATH),
PXD004242 (Geyer et al., weight-loss plasma, DDA/MaxQuant), and PXD062541
(epicatechin supplementation, DIA-NN). No new data were
generated. Derived tables inherit the licensing of their source depositions;
the code in this repository is MIT licensed.
